# Features

Feature-Module nach Domain organisiert, z.B.:

- `auth/` – Session, Login, Signup
- `finances/` – Finanzen & Einkäufe
- `cleaning/` – Putzplan
- `organization/` – Organisation & Kommunikation
- `pantry/` – Vorrat

Jedes Feature enthält Hooks, Services und UI-Komponenten für seinen Bereich.
